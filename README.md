# ColorTimerMaui

.NET MAUI color timer (`MauiApp1`). `TimerService` and `ColorService` drive the main page; Android, iOS, Mac Catalyst, Windows, and Tizen heads are under `Platforms/`.

## Stack

C#, .NET MAUI, XAML.

## Run

Open `MauiApp1.sln` in Visual Studio and deploy to a simulator or device.
